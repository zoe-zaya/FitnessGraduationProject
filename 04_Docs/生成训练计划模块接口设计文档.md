# 训练计划生成模块 V2.1 接口设计文档

**文档版本**：2.1\
**最后更新**：2026 年 4 月 15 日\
**适用系统**：基于深度学习的健身管理系统\
**接口版本**：/api/plan/v2

***

## 一、接口概述

### 1.1 设计原则

| 原则         | 说明                |
| :--------- | :---------------- |
| RESTful 风格 | 资源定位清晰，HTTP 方法语义化 |
| 统一响应格式     | 所有接口返回统一的数据结构     |
| 身份认证       | 所有接口需携带 JWT Token |
| 版本控制       | 接口路径包含版本号/v2      |
| 错误处理       | 统一错误码和错误信息格式      |

### 1.2 基础信息

| 项目   | 说明                                     |
| :--- | :------------------------------------- |
| 基础路径 | `/api/plan/v2`                         |
| 数据格式 | JSON                                   |
| 字符编码 | UTF-8                                  |
| 认证方式 | Bearer Token (JWT)                     |
| 请求头  | `Authorization: Bearer <access_token>` |
| 内容类型 | `Content-Type: application/json`       |

### 1.3 统一响应格式

**成功响应**：

```json
{
  "code": 200,
  "message": "success",
  "data": { ... }
}
```

**错误响应**：

```json
{
  "code": 400,
  "message": "错误描述信息",
  "data": null
}
```

## 三、接口详细说明

### 3.1 生成训练计划

**接口路径**：`POST /api/plan/v2/generate`

**功能描述**：根据用户身体数据、健身目标、训练部位和器材清单生成个性化训练计划

**请求参数**：

| 参数名            | 类型     | 必填 | 说明                           | 示例值                                      |
| :------------- | :----- | :- | :--------------------------- | :--------------------------------------- |
| inventory\_id  | String | 是  | 目标器材清单 ID                    | `"790bb4f7-7039-4d94-914c-701c99b4b83c"` |
| plan\_type     | String | 是  | 计划类型（FAT\_LOSS/MUSCLE\_GAIN） | `"FAT_LOSS"`                             |
| scheme\_type   | String | 否  | 分化方案（仅增肌计划需要）                | `"THREE_SPLIT"`                          |
| training\_part | String | 否  | 训练部位                         | `"胸部"`                                   |
| plan\_name     | String | 否  | 计划名称（可选，默认自动生成）              | `"减脂训练计划"`                               |

**plan\_type 可选值**：

- `FAT_LOSS`：减脂计划
- `MUSCLE_GAIN`：增肌计划

**scheme\_type 可选值**（仅增肌计划）：

- `ONE_SPLIT`：一分化方案
- `TWO_SPLIT`：二分化方案
- `THREE_SPLIT`：三分化方案
- `FOUR_SPLIT`：四分化方案

**training\_part 可选值**：

- 减脂计划：可不传或传 `"全身"`
- 增肌计划：`"胸部"`/`"背部"`/`"肩部"`/`"手臂"`/`"腿部"`/`"臀部"`/`"核心"`

**请求示例**：

```json
{
  "inventory_id": "790bb4f7-7039-4d94-914c-701c99b4b83c",
  "plan_type": "MUSCLE_GAIN",
  "scheme_type": "THREE_SPLIT",
  "training_part": "胸部",
  "plan_name": "胸部增肌计划"
}
```

**响应参数**：

| 参数名              | 类型       | 说明      |
| :--------------- | :------- | :------ |
| plan\_id         | String   | 计划唯一标识符 |

| fitness\_goal    | String   | 健身目标    |
| training\_part   | String   | 训练部位    |
| sessions         | Array    | 三阶段详情   |
| weekly\_schedule | Array    | 7 天训练日程 |

| 400 | 减脂计划不需要分化方案      | plan\_type=FAT\_LOSS 时 scheme\_type 应为空   |
| 400 | 请先完善身体数据后再生成训练计划 | 用户身体数据不完整                                 |
| 400 | 器材清单为空，请先添加器材    | 器材清单内无器材                                  |
| 404 | 器材清单不存在或无权访问     | 器材清单 ID 无效或不属于当前用户                        |

### 3.7 添加动作项

**接口路径**：`POST /api/plan/v2/addAction/{plan_id}`

**功能描述**：添加指定动作到训练计划（需符合器材约束）

**请求参数**：

| 参数名      | 类型     | 位置   | 必填 | 说明    |
| :------- | :----- | :--- | :- | :---- |
| plan\_id | String | Path | 是  | 计划 ID |

**请求体**：

| 参数名                    | 类型      | 必填 | 说明                     |
| :--------------------- | :------ | :- | :--------------------- |
| session\_id            | String  | 是  | 目标阶段 ID                |
| action\_id             | String  | 是  | 要添加的训练动作 ID            |
| sets                   | Integer | 否  | 组数（1-6）                |
| reps\_per\_set         | Integer | 否  | 每组次数（5-20）             |
| rest\_seconds\_default | Integer | 否  | 默认休息时长（30-300 秒，默认 60） |
| duration\_seconds      | Integer | 否  | 单次执行时长（秒）              |
| duration\_minutes      | Integer | 否  | 有氧动作时长（分钟）             |
| execution\_notes       | String  | 否  | 执行备注                   |

**请求示例**：

```json
{
  "session_id": "session_2...",
  "action_id": "act_054",
  "sets": 4,
  "reps_per_set": 12,
  "rest_seconds_default": 60,
  "execution_notes": "注意保持核心收紧"
}
```

**响应参数**：

| 参数名                      | 类型      | 说明     |
| :----------------------- | :------ | :----- |
| item\_id                 | String  | 动作项 ID |
| action\_id               | String  | 动作 ID  |
| action\_name             | String  | 动作名称   |
| action\_category         | String  | 动作类别   |
| difficulty\_level        | String  | 难度等级   |
| target\_muscles          | Array   | 目标肌群   |
| sets                     | Integer | 组数     |
| reps\_per\_set           | Integer | 每组次数   |
| rest\_seconds\_default   | Integer | 默认休息时长 |
| duration\_seconds        | Integer | 单次执行时长 |
| duration\_minutes        | Integer | 有氧动作时长 |
| lateral\_coeff           | Integer | 侧数系数   |
| total\_duration\_seconds | Integer | 总执行时长  |
| execution\_notes         | String  | 执行备注   |
| weight\_records          | Array   | 重量记录   |

**错误码**：

| 错误码 | 错误信息             | 说明          |
| :-- | :--------------- | :---------- |
| 400 | 该动作所需器材您当前健身房未配备 | 动作器材不在器材清单中 |
| 404 | 训练计划不存在或无权访问     | 计划 ID 无效    |
| 404 | 动作不存在            | 动作 ID 无效    |

***

**接口路径**：`PUT /api/plan/v2/updateAction/{plan_id}/{item_id}`

**功能描述**：修改训练计划中指定动作的参数（组数、次数、休息时长、重量记录等）

**请求参数**：

| 参数名      | 类型     | 位置   | 必填 | 说明     |
| :------- | :----- | :--- | :- | :----- |
| plan\_id | String | Path | 是  | 计划 ID  |
| item\_id | String | Path | 是  | 动作项 ID |

**请求体**：

| 参数名                    | 类型      | 必填 | 说明               |
| :--------------------- | :------ | :- | :--------------- |
| sets                   | Integer | 否  | 组数（1-6）          |
| reps\_per\_set         | Integer | 否  | 每组次数（5-20）       |
| rest\_seconds\_default | Integer | 否  | 默认休息时长（30-300 秒） |
| duration\_seconds      | Integer | 否  | 单次执行时长（秒）        |
| duration\_minutes      | Integer | 否  | 有氧动作时长（分钟）       |
| execution\_notes       | String  | 否  | 执行备注             |
| weight\_records        | Array   | 否  | 每组训练重量记录（kg）     |

**请求示例**：

```json
{
  "sets": 4,
  "reps_per_set": 12,
  "rest_seconds_default": 90,
  "weight_records": [50.0, 50.0, 47.5, 45.0]
```

**响应参数**：同 3.7 添加动作项响应

**错误码**：

| 错误码 | 错误信息        | 说明                |
| :-- | :---------- | :---------------- |
| 404 | 动作项不存在或无权修改 | 动作项 ID 无效或不属于当前计划 |

| :-- | :--------------- | :----------- |
| 400 | 该动作所需器材您当前健身房未配备 | 新动作器材不在器材清单中 |
| 404 | 动作项不存在           | 动作项 ID 无效    |
| 404 | 新动作不存在           | 新动作 ID 无效    |

***

### 3.11 延后训练

**接口路径**：`POST /api/plan/v2/postponeSchedule/{plan_id}/{schedule_id}`

**功能描述**：延后指定训练日程（支持 1-3 天）

**请求参数**：

| 参数名          | 类型     | 位置   | 必填 | 说明    |
| :----------- | :----- | :--- | :- | :---- |
| plan\_id     | String | Path | 是  | 计划 ID |
| schedule\_id | String | Path | 是  | 日程 ID |

**请求体**：

| 参数名  | 类型      | 必填 | 说明        |
| :--- | :------ | :- | :-------- |
| days | Integer | 是  | 延后天数（1-3） |

**请求示例**：

```json
{
  "days": 2
}
```

**响应示例**：

```json
{
  "code": 200,
  "message": "训练已延后 2 天",
  "data": {
    "new_scheduled_date": "2026-04-17",
    "remaining_postpone_days": 1
  }
}
```

**错误码**：

| 错误码 | 错误信息                | 说明                         |
| :-- | :------------------ | :------------------------- |
| 400 | 已达到最大延后次数限制（最多 3 天） | postpone\_count + days > 3 |
| 400 | 休息日不可延后             | 日程状态为 REST                 |
| 404 | 训练日程不存在或无权访问        | 日程 ID 无效或不属于当前用户           |
