# TFit 健身应用设计系统

## 1. 视觉主题与氛围

TFit 是一款现代化的健身应用，专注于健身器材识别和个性化健身计划生成。设计风格融合了 iOS 的简洁美学与健身行业的活力感，以深红色为主色调，营造出专业、动感且值得信赖的视觉体验。

应用采用白色作为基础背景，搭配深红色（`#a03e40`）作为品牌主色调，创造出清晰、有力的视觉层次。整体设计注重功能性与美观性的平衡，通过玻璃质感的卡片、精致的阴影效果和合理的空间布局，打造出既现代又专业的用户界面。

**核心特征：**
- 白色背景与深红色（`#a03e40`）作为品牌主色调
- Manrope 字体，清晰现代，适合数字界面
- 玻璃质感卡片设计，增强视觉层次感
- 基于 8rpx 的尺寸系统，确保界面元素比例协调
- 响应式设计，适配不同设备屏幕
- 强调功能性，同时保持视觉吸引力

## 2. 色彩 palette 与角色

### 品牌主色
- **健身红** (`#a03e40`): 品牌主色调，用于标题、链接和强调元素
- **健身红变体** (`#d8696a`): 按钮背景色，增强视觉焦点
- **健身红浅** (`rgba(251, 231, 231, 0.5)`): 辅助背景色，用于突出显示

### 文本颜色
- **近黑色** (`#1B1C1C`): 输入文本，清晰易读
- **深棕色** (`#564241`): 标签文本，提供层次感
- **中灰色** (`#8E8E93`): 次要文本，描述性内容
- **深红色** (`#a03e40`): 链接文本，强调可点击元素

### 背景与表面
- **纯白色** (`#FFFFFF`): 页面背景，卡片表面
- **玻璃背景** (`rgba(252, 249, 248, 0.7)`): 表单区域，增强视觉层次感
- **浅灰色** (`#F2F2F7`): 次要背景，区分不同内容区域

### 边框与阴影
- **边框色** (`#efefef`): 卡片边框，微妙分隔
- **阴影** (`rgba(0, 0, 0, 0.12)`): 卡片阴影，增强深度感

## 3. 排版规则

### 字体家族
- **主要字体**: `Manrope`，现代无衬线字体，清晰易读
- **备选字体**: 系统默认无衬线字体

### 字体层次结构

| 角色 | 字体 | 大小 | 字重 | 行高 | 备注 |
|------|------|------|------|------|------|
| 应用标题 | Manrope | 64rpx | 700 | 1.2 | 应用名称 "TFit" |
| 页面标题 | Manrope | 48rpx | 700 | 1.3 | 页面主要标题 |
| 表单标签 | Manrope | 24rpx | 700 | 1.4 | 输入框标签 |
| 按钮文本 | Manrope | 32rpx | 700 | 1.2 | 按钮标签 |
| 正文文本 | Manrope | 24rpx | 400 | 1.4 | 普通文本 |
| 链接文本 | Manrope | 24rpx | 700 | 1.4 | 可点击链接 |
| 提示文本 | Manrope | 24rpx | 525 | 1.4 | 说明性文本 |

### 排版原则
- **一致性**: 整个应用保持统一的字体风格和大小比例
- **可读性**: 优先考虑文本的清晰易读，尤其是在移动设备上
- **层次感**: 通过字重和大小的变化，创建明确的视觉层次
- **强调重点**: 重要元素使用加粗字体，引导用户注意力

## 4. 组件样式

### 按钮

**主要按钮**
- 背景: `#d8696a` (健身红变体)
- 文本: `#FFFFFF`
- 高度: 96rpx
- 圆角: 32rpx
- 字体: Manrope, 32rpx, 700
- 禁用状态: 透明度 0.6

**次要按钮**
- 背景: 透明
- 文本: `#a03e40` (健身红)
- 字体: Manrope, 24rpx, 700

### 输入框
- 背景: `#FFFFFF`
- 边框: 2px solid `rgba(160, 62, 64, 0.1)`
- 聚焦状态: 边框颜色变为 `rgba(160, 62, 64, 0.4)`
- 圆角: 32rpx
- 内边距: 左侧 12rpx (为图标留出空间)
- 字体: Manrope, 32rpx

### 卡片与容器
- 背景: `rgba(252, 249, 248, 0.7)` (玻璃质感)
- 圆角: 32rpx
- 阴影: `0 2rpx 10rpx rgba(0, 0, 0, 0.12)`
- 内边距: 64rpx

### 复选框
- 未选中: 2px 边框 `rgba(160, 62, 64, 0.1)`，背景 `#FFFFFF`
- 选中: 背景 `#d8696a`，白色勾选标记
- 大小: 40rpx x 40rpx
- 圆角: 16rpx

### 图标
- 使用 uni-icons 组件库
- 颜色: 主要图标使用 `#8E8E93`
- 大小: 根据上下文调整，通常为 20-24rpx

## 5. 布局原则

### 间距系统
- 基础单位: 8rpx
- 尺寸 scale: 8rpx, 16rpx, 24rpx, 32rpx, 40rpx, 48rpx, 64rpx, 80rpx, 96rpx
- 表单元素间距: 24rpx
- 区域间距: 40rpx

### 网格与容器
- 页面容器: 全屏，带背景图片
- 表单区域: 居中，玻璃质感卡片
- 响应式布局: 适配不同屏幕尺寸

### 空白哲学
- **功能性空白**: 合理的间距确保界面元素不拥挤，提高可读性
- **视觉层次**: 通过空白区域区分不同功能模块
- **焦点引导**: 重要元素周围留有足够空白，引导用户注意力

### 边框圆角 scale
- 小 (16rpx): 小按钮，复选框
- 标准 (32rpx): 输入框，卡片
- 大 (48rpx): 特殊容器

## 6. 深度与层次

| 层级 | 处理方式 | 用途 |
|------|----------|------|
| 平面 (Level 0) | 无阴影 | 页面背景 |
| 卡片 (Level 1) | `0 2rpx 10rpx rgba(0, 0, 0, 0.12)` | 表单区域，内容卡片 |
| 聚焦 (Level 2) | 边框颜色变化 | 输入框聚焦状态 |
| 悬浮 (Level 3) | 微妙的阴影变化 | 按钮悬浮效果 |

**阴影哲学**: 使用适度的阴影效果增强界面深度感，避免过度使用导致视觉混乱。玻璃质感的卡片设计创造出现代、轻盈的视觉效果。

## 7. 设计规范

### 建议
- 使用 `#1B1C1C` 作为输入文本颜色，确保清晰易读
- 应用深红色 (`#a03e40`) 作为品牌主色调，用于标题、链接和强调元素
- 使用 Manrope 字体，保持统一的视觉风格
- 应用玻璃质感卡片设计，增强视觉层次感
- 使用基于 8rpx 的尺寸系统，确保界面元素比例协调
- 为所有可交互元素提供明确的视觉反馈

### 避免
- 避免使用纯黑色 (`#000000`) 作为文本颜色
- 避免过度使用深红色，保持视觉平衡
- 避免使用不同字体，保持一致性
- 避免使用尖锐的边角，保持圆角设计
- 避免使用过重的阴影，保持界面轻盈感

## 8. 响应式行为

### 断点
| 名称 | 宽度 | 关键变化 |
|------|------|----------|
| 移动设备 | <750rpx | 单列布局，紧凑表单 |
| 平板设备 | 750rpx-1024rpx | 双列布局，扩展表单 |
| 桌面设备 | >1024rpx | 多列布局，完整功能 |

### 触摸目标
- 按钮最小尺寸: 80rpx x 80rpx
- 输入框高度: 96rpx
- 链接区域: 足够大的点击区域
- 表单元素间距: 确保手指操作不拥挤

### 折叠策略
- 导航栏: 从完整导航到汉堡菜单
- 表单: 从多列到单列
- 内容: 从网格到列表

### 图片行为
- 背景图片: 自适应屏幕尺寸
- 图标: 保持比例，响应式调整大小
- 健身器材图片: 保持清晰，适当缩放

## 9. 组件示例

### 登录页面
- 背景: 健身相关背景图片
- Logo 区域: 应用 logo + 应用名称 + 标语

- 按钮: 红色登录按钮，白色文字

### 注册页面
- 背景: 与登录页面一致
- 表单区域: 包含手机号、密码、确认密码输入框
- 密码提示: 密码复杂度要求说明
- 协议同意: 自定义复选框 + 用户协议和隐私政策链接
- 按钮: 红色注册按钮
- 链接: 已有账号登录链接

### 输入框
- 左侧图标: 手机号或密码图标
- 输入区域: 白色背景，圆角边框
- 聚焦状态: 边框颜色变化
- 密码输入: 带眼睛图标，可切换可见性

### 按钮
- 主要按钮: 红色背景，白色文字，圆角设计
- 次要按钮: 透明背景，红色文字
- 禁用状态: 半透明效果

## 10. 设计迭代指南

1. **保持一致性**: 确保所有页面使用统一的颜色、字体和组件样式
2. **注重功能性**: 优先考虑用户体验和功能实现，再考虑视觉效果
3. **响应式设计**: 确保在不同设备上都有良好的显示效果
4. **性能优化**: 避免过度使用复杂的视觉效果，确保应用流畅运行
5. **用户反馈**: 根据用户反馈不断优化设计，提高用户满意度
