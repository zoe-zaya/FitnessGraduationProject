# 解决无法删除健身房的问题

## 问题分析

根据之前的错误信息，删除健身房时出现外键约束错误。当前已处理的关联关系：

1. training\_plan → equipment\_inventory (inventory\_id)
2. plan\_session → training\_plan (plan\_id)
3. session\_action\_item → plan\_session (session\_id)
4. training\_schedule → training\_plan (plan\_id)

但删除仍然失败，可能存在以下问题：

1. 级联删除没有正确触发
2. 存在其他未处理的外键关联
3. 删除顺序不正确

## 解决方案

### 步骤 1：检查数据库外键约束

* 查看所有引用 `equipment_inventory` 表的表

* 查看所有引用 `training_plan` 表的表

* 确认是否启用了级联删除

### 步骤 2：修改删除逻辑

在 `app/api/equipment.py` 的 `delete_inventory` 函数中：

1. 先删除所有关联的训练计划
2. 对于每个训练计划，删除其所有关联数据：

   * training\_schedule

   * plan\_session

   * session\_action\_item
3. 删除器材关联关系
4. 最后删除健身房

### 步骤 3：添加详细日志

* 记录删除过程中的每一步

* 记录删除的数据数量

* 记录具体的错误信息

### 步骤 4：测试验证

* 测试删除包含训练计划（有器材）的健身房

  * 删除成功

* 测试删除不包含训练计划但包含器材的健身房

  * 删除成功

* 测试删除不包含训练计划和器材的健身房

  * 删除成功

* 确认所有关联数据都被正确删除

  * 删除成功
